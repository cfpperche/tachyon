# Departure Mono (optional Tachyon UI face)

Vendored so Control → Settings can offer this family without a network fetch.

- Family: Departure Mono
- Version: 1.500
- Source: https://github.com/rektdeckard/departure-mono (public/assets)
- License: SIL Open Font License 1.1 (`OFL.txt`)
- Bundled weights: Regular 400 only — that is the only face upstream ships
- SHA-256 of `DepartureMono-Regular.woff2`: `5b4fed1daa90708aa9c6ee1190abca9dc22164a1c1def0020386e46b61038cfb`

Tachyon Mono (JetBrains Mono) remains the default. This directory is the opt-in second family.

Build output copies these files to `dist/webview/fonts/departure`.
