## What a gate can and cannot say

From this session, a reader that subscribed to the existing stdio stream can
say, at the moment `turn/completed` arrives for T:

- **This turn had a plan** if at least one `turn/plan/updated` with
  `turnId === T` was seen. The last such notification is the complete plan
  (schema: `plan` is required and is the full ordered list).
- **This turn finished without a plan** if none was seen. That is mute, not
  `plan: []`.
- **This turn is still running** only while `turn/completed` (or
  `interrupted` / `failed`) has not arrived. That wait is ordinary turn
  lifetime, not a plan timeout.

It cannot, from `turn/completed.items` alone, tell those two cases apart:
both summaries were one `agentMessage`. It cannot treat a previous turn's
plan as this turn's plan unless it keeps that itself — turn 2 did not
re-emit the tea plan. There is no `turn/plan/cleared`. Thread-level
“current plan” after a mute follow-up was not readable after process exit:
the thread was `ephemeral`, and `thread/resume` returned
`no rollout found for thread id …`. Live capture is the channel.

## Gotchas (measured)

1. **This agent's `$HOME` is remapped** to
   `/home/goat/tachyon/.tachyon/bridge-mcp/poccodex.grok`. A child `codex`
   started without `CODEX_HOME=/home/goat/.codex` sees `account: null` and
   then 401s against `https://api.openai.com/v1/responses` (“Missing bearer
   or basic authentication”). Two such turns completed with
   `turn/completed` `status=failed` and a mute plan channel — that is
   “failed before the model”, not “model chose no plan”. Same remap trap
   as `docs/research/t-bcf9e5-local-usage-rate-limit.md`. The product
   collector runs in the host process and does not hit this; a probe
   inside a remapped agent must set `CODEX_HOME`.
2. **`turn/completed.items` is a summary.** `itemsView` was `"summary"` on
   both successes. Do not infer “no plan” from a missing plan item there.
3. **`item/plan/delta` is not a fallback.** It did not appear. The
   generated schema still marks it EXPERIMENTAL and says concatenated
   deltas may not match the completed plan.
4. **A previous plan is not restated.** After measure 1, measure 2 was
   mute. Per-turn absence is still true. A thread-scoped “is there a plan
   at all?” would have to remember the last `turn/plan/updated` itself.
