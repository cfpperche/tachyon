POC — Focus line na sidebar

Com muitos agentes, badges (model, branch, CPU, continuity) não respondem “em que tarefa cada um está”. Esta POC projeta uma linha de foco por agente, com prioridade: task MC → spawn brief → continuity goal. Clica numa row para ver a fonte completa.

Controles da POC

Prioridade da fonte

task Mission Control: assignee = agente, status open
brief Spawn contract / taskBrief (filho ad-hoc)
goal Continuity: linha “# Current Goal”
— Sem fonte → linha omitida (não inventa trabalho)
Clica num agente à esquerda para inspecionar a focus line.
O que validar com o olho: (1) dá para achar “quem está em t-…” sem abrir terminal? (2) filhos ad-hoc herdam o brief do spawn? (3) continuity stale ainda mostra goal útil?
