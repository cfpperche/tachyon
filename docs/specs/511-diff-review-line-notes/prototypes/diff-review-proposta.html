A regra que decide o desenho: deslocamento mecânico migra; linha apagada ou match ambíguo vira outdated. Nunca flutuar em silêncio para uma linha qualquer. O mecanismo não finge precisão.

A bifurcação que precisa ser tratada nas duas pontas

O lado modificado do diff tem duas formas hoje, e isso decide quanto a plataforma nos dá de graça.

SituaçãoURI do lado atualRange acompanha edição?Quem paga a continuidade
agente com headRef tachyon-worktree:/<path>?ref=<headRef> não conteúdo imutável por definição nós, inteira
sem headRef vscode.Uri.file(...) — arquivo real sim decoração de modelo plataforma na tela aberta
Duas portas para o mesmo efeito — a classe de defeito que este projeto mais sofre. Se a implementação tratar só a porta do arquivo real, o comentário funciona num caso e mente no outro. Os dois caminhos têm que virar caso de teste nomeado.
