- [x] **Step 3 — engine `skill-dir` install/remove path (I/O).** `previewInstall` plans `skillTargets` (each with a `collision` flag = a dest exists that isn't this plugin's prior skill-dir) and binds them into the consent fingerprint; `applyInstall` takes `skillDecisions` (per-dest `keep|replace`), **fails closed on an undecided collision** (never a silent overwrite/skip), materializes each consented skill (committed payload → runtime skills dir), records `skill-dir` lockfile targets, and on update **cleans up stale skill-dirs** the new version dropped. `applyRemove` deletes exactly the recorded skill-dirs (no backup/restore — D5). **Security (codex NEEDS-REVISION ×2 → 4 HIGH folded → confirming SHIP):** a TOCTOU copy-guard (a clean dest that *appeared* since preview is refused); update stale-cleanup so an updated-away skill is never orphaned; and `validSkillDest` (`<skillsRel>/<one-kebab>`) gates **every** lockfile skill-dir trust/delete path (applyInstall collision-suppression + stale-cleanup, planRemove) so a corrupted lockfile can never delete/overwrite a non-skill path. ## Closure
**Closure:** spec 251 v1 SHIPPED — skills are the second plugin capability (after hooks), common-denominator-first. A plugin ships skills as a **neutral `skills/<name>/SKILL.md` payload** (written once); each present, skills-capable runtime's adapter materializes it to its own location (claude `.claude/skills/`, codex `.agents/skills/` — both verified vs official docs). Install/update/remove are consent-bound (TOCTOU fingerprint) and **collision-safe**: a user's existing skill is never silently overwritten — the consent drawer surfaces each collision with a **Keep / Replace** control, Replace requires a **double confirmation** (D5: destructive, no backup), and the engine **fails closed** on an undecided collision and on a corrupted lockfile skill-dir target (`validSkillDest` gates every trust/delete path). 5 steps, each adversarially codex-reviewed (Steps 1 & 3 took two rounds — 4 HIGH security findings folded — before a confirming SHIP). ~40 plugin tests across skill/manifest/engine/consent; 1229 suite green at close. Deferred: namespacing (OQ3 — bare name + Keep/Replace chosen), user-level skills (project-level only), and MCP as the next capability after skills.
